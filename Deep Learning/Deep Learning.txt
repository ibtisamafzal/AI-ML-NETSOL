Introduction:

Neural Network:
Input Layer
Hidden Layer
Output Layer

Types of Neural Networks:

1. FeedForward Neural Networks (FNNs):
- No Backpropagation -> It repeats the process from start instead of moving a step back.
- Data flow in one direction -> Classification Tasks


2. Convolutional Neural Networks (CNNs): Image Data:
- Grid-like data -> Images
- Edge detection


3. Recurrent Neural Networks (RNNs):
- Input (X), Output (Y), Weights, Hidden State (S) -> Stores previous input
- LSTM and GRUs (Natural Language)



4. Generative Adversarial Networks (GANs)

5. Autoencoders
6. Transformer Networks
