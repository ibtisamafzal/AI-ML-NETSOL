Natural Language Processing:
- Enables computers to work with human language

NLP Pipeline:
Raw Text -> Cleaning -> Sentence Tokenization -> Word Tokenization -> Normalization -> Stopward Removal -> Stemming/Lemmatization -> POS Tagging -> NER/Chunking -> Feature Extraction -> Machine Learning Model -> Prediction

Example: "I loved the new iPhone from Apple"


Library Used: Spacy
