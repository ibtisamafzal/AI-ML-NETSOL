# AI/ML Training at NETSOL Technologies Pakistan

This repository documents my hands-on work, exercises, and projects from the **3-month AI/ML Training Program** at **NETSOL Technologies Pakistan**.

I followed a **"Learning in Public"** approach — sharing weekly progress on [LinkedIn](https://www.linkedin.com/in/ibtisamafzal) alongside pushing all practical code here.

## 📋 Program Overview

- **Duration:** 3 Months (12 Weeks)
- **Format:** 3 hours/day — 20% Theory, 80% Practical
- **Focus Areas:** Artificial Intelligence, Machine Learning, Deep Learning, Natural Language Processing, and Microsoft Azure AI

## 🛠️ Topics Covered

### Week 1 — Linux & Python Foundations
- Linux shell scripting fundamentals (file operations, permissions, process management)
- Python basics: variables, data types, operators
- Data structures: lists, tuples, dictionaries, sets
- Conditional statements, loops, list comprehension

### Week 2 — OOP & Descriptive Statistics
- Object-Oriented Programming: classes, objects, constructors/destructors
- Inheritance (multilevel, hierarchical, multiple) and Method Resolution Order
- Access specifiers, encapsulation, polymorphism, operator overloading, magic methods
- Descriptive statistics: measures of central tendency, dispersion, and position

### Week 3 — Probability & NumPy
- Probability theory: joint, marginal, conditional probability
- Probability distributions and Bayesian probability
- NumPy: array creation, indexing, slicing, reshaping, broadcasting, vectorized operations
- Introduction to Pandas: Series, DataFrames, selection, missing data

### Week 4 — Pandas, Seaborn & Machine Learning Intro
- Pandas: merging, joining, concatenation, GroupBy, binning, data output
- Plotting with Pandas and Seaborn: distribution, categorical, and matrix plots (heatmaps)
- Machine learning fundamentals: types of ML and the classical ML pipeline
- Supervised learning: regression vs. classification, cost function, optimizer
- Univariate linear regression with gradient descent (loop-based and vectorized)

### Week 5 — Machine Learning I: Regression & Classification
- Multivariate linear regression
- Polynomial regression
- Logistic regression: binary and multiclass classification
- Code practice with scikit-learn

### Week 6 — NLP & Machine Learning II
- **Natural Language Processing:** text pre-processing with NLTK/spaCy, noise removal, tokenization, stemming, lemmatization, text normalization, regular expressions
- **Linguistic analysis:** POS tagging, named entity recognition, chunking, WordNet
- **Text features:** Bag-of-Words, feature extraction, document similarity
- **Model evaluation:** evaluation metrics for classification and regression, handling imbalanced datasets
- **Classical ML models:** Support Vector Machines, Decision Trees, Random Forest (bagging)

### Week 7 — Deep Learning I
- Boosting
- Multi-Layer Perceptron (feed-forward neural networks): forward and backward passes, activation functions, cross-entropy, computational graphs and backpropagation
- Vanishing and exploding gradients, overfitting and underfitting, dropout regularization
- Implementing neural networks with TensorFlow / PyTorch / Keras
- Convolutional Neural Networks: 2D CNN for image classification, 1D CNN for text classification

### Week 8 — Deep Learning II: Recurrent Networks
- Recurrent Neural Networks (RNNs)
- Long Short-Term Memory networks (LSTM)
- Gated Recurrent Units (GRU)
- LSTM and GRU code practice

### Week 9 — Word Embeddings & Sequence Models
- Word embeddings: Word2Vec, Continuous Bag-of-Words, Continuous Skip-gram
- Training custom embeddings with Gensim
- Sequence model architectures: one-to-one, one-to-many, many-to-one, many-to-many

### Week 10 — Attention & Project
- Bi-directional LSTM/RNN in sequence models
- Attention mechanism
- Project selection and architecture planning

### Week 11 — Microsoft Azure AI Services I
- Selecting the right Azure AI service for vision, language, decision support, and speech solutions
- Securing Azure AI services (account keys, authentication, virtual networks) and Responsible AI principles
- Creating, monitoring, and managing Azure AI resources and costs
- Deploying Azure AI services: endpoints, CI/CD integration, containers
- Solutions with Anomaly Detector, Content Moderator, Personalizer, Metrics Advisor, and Immersive Reader
- Computer vision: image analysis, text extraction from images, image classification and object detection with Custom Vision

### Week 12 — Microsoft Azure AI Services II
- Video processing
- Azure NLP solutions: text analysis, speech processing, translation
- Language understanding models and question answering
- Knowledge mining and conversational AI solutions

### Beyond the Course Outline
- Autoencoders
- Graph Neural Networks (GNN)
